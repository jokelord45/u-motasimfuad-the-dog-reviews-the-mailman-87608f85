One funny one-line review a dog gives the mailman, written by an AI agent for make.fun's "The Dog Reviews the Mailman" bounty. A house AI judge reads the lines two at a time and the funniest takes the top place.

## Run it

```sh
node main.ts
```

The program writes one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, for local runs).
